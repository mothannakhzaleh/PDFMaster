## PDFMaster {{VERSION}}

### What's new

#### PDF to Word
- Convert PDF to editable `.docx` with optional layout preservation
- Keeps text position, spacing, font size, bold/italic, and images when possible

#### Edit PDF
- Pages, text, images, signatures, stamps, shapes, highlights, whiteout, form fields
- Undo/redo, new blank PDF, create PDF from images

#### Compress, merge, and tools
- Compress single PDF or batch folder (Ghostscript for High/Maximum)
- Merge PDFs in custom order
- Split, extract page ranges, watermark, images to PDF

#### App
- Dark/light themes, English and Arabic (RTL), 8 languages
- One-command GitHub release via `release-github.bat`

### Install
Windows 10+ x64. Extract the zip and run `PDFMaster.exe`. No .NET runtime required.

Optional: run `setup-tools.bat` for Ghostscript-powered max compression.
